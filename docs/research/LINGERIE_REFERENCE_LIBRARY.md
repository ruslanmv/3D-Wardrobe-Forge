# Lingerie reference library

What the lingerie generator may take from outside this repository, where it is kept, how
it is fetched and checked, and what each source actually contains. The record of truth is
`assets/reference/lingerie/sources.lock.json`; this page is written from it (2026-10-24).

## Layout

```
assets/reference/lingerie/
  sources.lock.json                    every source: licence, pinned version, contents, use class, files + SHA-256
  patterns/bracuppattern/              Apache-2.0 copy (unmodified) + LICENSE + bracuppattern-cup.json
  patterns/freesewing-uma/             MIT copy (unmodified) + LICENSE + uma-draft.json
  measurements/garmentcode/            MIT copy (unmodified) + LICENSE + garmentcode-mean-female.json
tools/data/
  fetch_lingerie_sources.py            fetch pinned files, refuse a hash that differs
  convert_lingerie_patterns.py         normalize the copies into the *.json (never executes them)
  verify_lingerie_sources.py           offline check: records complete, files pinned and licensed, JSON current
```

Body measurements this repository already had stay where they were: ANSUR II in
`assets/anatomy/reference-sizes.json`, MakeHuman and the Human Reference Atlas pelvis
beside it, each with its own provenance file. The lock points at them; nothing is copied.

## Commands

```bash
python tools/data/verify_lingerie_sources.py          # offline; CI runs it as tests/unit/test_lingerie_sources.py
python tools/data/fetch_lingerie_sources.py --refresh # re-download every pinned file and check its hash
python tools/data/convert_lingerie_patterns.py        # rewrite the normalized JSON after a source update
```

## Adding a source

1. Inspect it first: clone or download outside the repository and read what is there.
   Record what it holds **and what it does not** — a repository called "bra" may hold a
   test fixture (Seamly2D's does).
2. Add a record to `sources.lock.json` with every field `verify_lingerie_sources.py`
   requires. Pin a commit or revision; never a branch URL.
3. Only for MIT, Apache-2.0, CC0 or CC BY 4.0 material: list the files to keep, including
   the licence, with `sha256: null`, then run
   `python tools/data/fetch_lingerie_sources.py --record` once. It refuses to overwrite a
   recorded hash.
4. GPL, paid, gated or research-only material keeps no files here: describe its method in
   our own words in `LINGERIE_MEASUREMENT_METHODS.md`, if it is useful at all.
5. If the generator is to read it, add a converter to `OUTPUTS` in
   `convert_lingerie_patterns.py` that writes millimetres and carries `provenance`.
