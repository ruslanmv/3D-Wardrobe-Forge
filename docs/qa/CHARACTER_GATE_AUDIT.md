## Policy: what opens the bare body state

| #   | Requirement                                                                                                         | Who acts         | Status under this policy          |
| --- | ------------------------------------------------------------------------------------------------------------------- | ---------------- | --------------------------------- |
| 1   | The file matches the library pin (same SHA-256)                                                                     | operator         | required                          |
| 2   | The file's own terms allow sexual expression (VRM 1.0 `allowExcessivelySexualUsage: true`; VRM 0.x `sexualUssageName: Allow`) | creator          | required                          |
| 3   | The licence permits modification (from the file's meta, or from its VRoid Hub licence URL when the meta says `unknown`) | creator          | required                          |
| 4   | The operator declares the character adult in `assets/library/policy.json`                                           | operator         | required                          |
| 5   | The authored body is closed under the clothes (`upper`, `lower`, thighs, shins)                                     | licensed 3D artist | required                        |
| 6   | The viewer confirms they are an adult in Private Mode                                                               | viewer           | required (at use time)            |
| —   | ~~A person records `clearly-adult` for the file's SHA-256 (independent design review)~~                             | —                | **no longer required**            |

The owner is responsible for judging that a character's appearance is adult.
That judgment is made through requirement 4, the operator's declaration. No
third-party or formal review step is part of this policy.

### Permanent hard blocks (unchanged)

No policy setting, declaration or confirmation opens any of these:

- a character that depicts, or appears to depict, a minor;
- non-consensual content;
- illegal content.

A file whose own terms refuse sexual expression also stays blocked
(requirement 2). Only a different file can fix that.

## What each needs

- nothing. The licence, terms, declaration and body all pass.

**Rinna** (`d88320f4b005`): eligible for the bare state

- nothing for the gate. The file's meta says `modification: unknown`. Its VRoid
  Hub licence URL says modification is allowed, and that answer is what passes
  requirement 3.
- Note: her clothing is painted onto the body texture. She has no separate
  clothing meshes (`docs/qa/body-state-specs/vroid-rinna.md`). Painted-on
  clothing cannot be hidden: `/v1/visibility` (CV1) has no garment to hide on
  her file. Only a separately built body-state file shows her without it.

**AvatarSample_O** (`e5c0395b59b6`): incomplete
