# Original anime-inspired beach and pool swimwear

**Scope corrected:** This release is **12 women's beach and swimming-pool swimsuit designs**, not costumes, cosplay or named anime-character clothing. All 12 looks are **original** designs intended for adult anime-style VRM avatars. No franchise names, logos, scraped reference art or third-party character assets are used.

## Implementation

- `wardrobe/pipeline/outfit_dictionary.py`: all 12 are swimwear entries using the existing supported `triangle bikini`, `bandeau bikini`, `one-piece swimsuit`, or `skirted swimsuit` planner vocabulary.
- `wardrobe/pipeline/occasions.py`: the 12 designs appear under Vacation → Beach (private-rated cards hidden without appropriate private mode) and Private → Anime Beachwear.
- `assets/swimwear/anime_beachwear_catalog.json`: original fashion-design targets and honest implementation gaps for UI display and iteration.
- The built-in swimwear adult requirement and original-avatar licensing policy are **unchanged**. The ordinary Vacation → Beach entry still retains a general-rated option.

**Fidelity warning:** These are palette/pattern variations on *four existing geometry families*. Distinct string ties, cut-outs, center knots, deep leg cuts, racerbacks and elaborate ruffles are visual targets, **not** validated mesh features. No image rendering or fit previews are included in this code change. Technical fit passing is not an artistic-fidelity pass.
