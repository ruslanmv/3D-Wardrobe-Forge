# bracuppattern — third-party files, unmodified

These files are byte-for-byte copies of the pinned upstream files listed for
`bracuppattern`
in `assets/reference/lingerie/sources.lock.json` (URL, commit, SHA-256, licence).
They are not modified here; `tools/data/fetch_lingerie_sources.py` refuses a copy
whose hash differs. What this repository derives from them is written by
`tools/data/convert_lingerie_patterns.py` to the `*.json` beside them.

The licence beside them (`LICENSE`) applies to these files, not to this repository.
